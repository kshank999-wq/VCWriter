
## A block quote asks for its source (21 November 2026)

From Ken: *the block quote at the end needs to ask you for the reference or
citation. And if you don't have it yet, it'll say need citation… you can just
use the drop-down list… the block quote is usually author and date, if not a
page number. So you can select that format.*

Under every block quote in a book's manuscript: a drop-down of the Reference
Library, reading **Needs citation** (amber) until a source is chosen, with
*New source in the library…* at its foot. Choosing one cites it at the quote's
end (`withTrailingCitation`); choosing again changes the source. Beside it, how
the citation reads — **Author and date** (the default for a quote) or the
book's citation style — and the page. An author-date citation (`form:
'author-date'`, migration 0091, applied live) reads *(Flesch, 1946, p. 42)* in
the text whatever the book's style, takes no footnote and no number, and is
shown in the page's chip as *Flesch 1946*, the full reading under the quote.
