# Dictionaries bundled with VC Writer

- `en.aff`, `en.dic`: the English Hunspell dictionary from the `dictionary-en`
  package (wooorm/dictionaries), MIT and BSD; see `LICENSE-dictionary-en`.
  Used for spelling in every right-click menu.
- `thesaurus.txt`: built from Moby Thesaurus II by Grady Ward (Project
  Gutenberg ebook #3202), placed in the public domain by its author. Rebuild
  with `node scripts/build-thesaurus.mjs path/to/mthesaur.txt`.
