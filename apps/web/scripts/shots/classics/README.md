# The classics the demo projects are built from

All of these are in the public domain in the United States. They are the
sample writing in VC Writer's screenshots and help guides (addendum 35 §10).

| File | Work | Source |
| --- | --- | --- |
| `great-expectations.txt` | Charles Dickens, *Great Expectations* (1861), chapters I–III | Project Gutenberg eBook #1400 |
| `poe-tales.txt` | Edgar Allan Poe, *The Tell-Tale Heart* (1843), *The Cask of Amontillado* (1846), *The Masque of the Red Death* (1842) | Project Gutenberg eBook #2148 |
| `hamlet-act-one-scene-one.json` | William Shakespeare, *Hamlet*, Act I, Scene I | Project Gutenberg eBook #1524 |
| `adaptations.mjs` | *Night of the Living Dead* (1968; public domain, released without a copyright notice), opening scenes written out from the film. Sherlock Holmes episodes after Arthur Conan Doyle, *The Adventures of Sherlock Holmes* (1892), with Doyle's own dialogue | the film; Project Gutenberg eBook #1661 |

Only the works' own text is kept here: Project Gutenberg's header, licence
and trademark are stripped, as its licence asks of anyone redistributing a
public-domain text without them.

Not used, because they are under copyright: *Chinatown* (1974) and Lynn
Nottage's *Sweat* (2015).
